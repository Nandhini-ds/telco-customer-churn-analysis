# Customer Churn Prediction
## Project Overview
This project focuses on analyzing customer churn in the telecommunications industry using SQL Server, Python, Machine Learning, and Power BI.

The objective is to understand customer churn patterns, identify important factors associated with churn, and develop a machine learning model to predict customer churn.
## 1. Data Loading & SQL
Loaded the Telco Customer Churn dataset into SQL Server.
Created a SQL View for analysis.
Connected SQL Server with Python using Pandas.
## 2. Exploratory Data Analysis
Analyzed the overall customer churn rate.
Studied churn across contract types, payment methods, tenure, monthly charges, and technical support.
Identified important patterns and factors associated with customer churn.
## 3. Data Cleaning & Preprocessing
Handled missing values.
Converted categorical and boolean features into suitable formats.
Performed feature engineering and prepared the dataset for machine learning.
Saved the cleaned dataset for further analysis.
## 4. Power BI Dashboard
Connected the prepared data to Power BI.
Created visualizations to analyze customer churn and related factors.
## 5. Machine Learning – Baseline Model
* Started the machine learning model-building phase.
* Built a **Logistic Regression** model as the baseline model.
* Achieved an accuracy of approximately **81%** on the test data.
* Further model development and evaluation will be performed to improve the prediction performance.
